# Підготовка до захисту практичної 1

Початкова точка — MainActivity.onCreate: setContent запускає MonitorApp. Compose описує інтерфейс як функцію поточного стану. Кнопка змінює mutableStateOf, тому Compose повторно виконує залежні від значення компоненти. Dashboard передає числа в MonitorLogic.dose, де є перевірки скінченності та невід’ємності. Формула D = P × t коректна для сталої потужності дози: мкЗв/год × год = мкЗв. Немає мережевого підключення до АЕС: значення навчальні. AuthScreen зберігає введення через rememberSaveable, а ViewModel виконує вхід асинхронно. Gradle задає SDK, залежності й типи збірки.

## Демонстрація

1. Запусти PW01; покажи поля входу й повідомлення для неправильного email.
2. Увійди як operator@demo.ua / Demo12345. Онови показник та поясни анімацію.
3. Введи 0,12 і 8: результат має бути 0,96 мкЗв. Потім перевір від’ємне значення.
4. Відкрий MonitorLogic.dose та відповідний тест; поясни одиниці вимірювання.

## Можливі питання

### Що означає декларативний UI?

Описую, як екран має виглядати для поточного стану; Compose застосовує зміни. Не шукаю TextView і не викликаю setText вручну.

### Що таке recomposition?

Повторне виконання composable, який читає змінений стан. Це не обов’язково перемальовування всього екрана; побічні ефекти треба виносити з тіла composable.

### remember і rememberSaveable — у чому різниця?

remember зберігає значення між рекомпозиціями. rememberSaveable додатково використовує механізм збереження стану для відновлення сумісних значень після відтворення Activity.

### Чому обчислення винесено з UI?

Доменна функція не залежить від Android. Її можна перевірити швидким JUnit-тестом і повторно використати на іншому екрані.

### Чому не приймаються NaN та Infinity?

Порівняння лише з нулем не виключає всі некоректні значення. isFinite перевіряє скінченність входів і результату множення.

### minSdk, targetSdk і compileSdk?

minSdk=26 задає найстарішу підтримувану ОС. compileSdk=35 — API для компіляції. targetSdk=35 визначає, для якої поведінки ОС застосунок адаптовано; це не максимальна версія Android.

### Чи може телефон виміряти радіацію?

У цьому проєкті — ні. Показники постів вигадані; SensorManager дає прискорення й кутову швидкість, а не дозу радіації.

## Вправа

Зміни початкову тривалість із 8 на 2 години й додай перевірку, що 0,12 × 2 = 0,24. Покажи, де змінюється UI, а де — тест.
